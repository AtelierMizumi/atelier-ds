# Changelog

## 0.1.0 (2026-11-18)

- Tokens: core colors, type scale, space, shape (tilt −9°, skew −12°), layout, motion, z-layers; semantic aliases; themes `atelier` (default) and `sixk`.
- Contrast pairs and hero menu tints checked for every theme by `npm test`.
- Base CSS and components: top bar, HUD, hero menu (wedge + cursor), slab heading, plate, paper, cut panel, buttons, round prompt buttons, chips, status, ledger, specs, callouts, gallery, TOC, pager, form field, utilities, scrim, wipe, sweep, CSS water fallback.
- JS: `input` (keyboard + gamepad navigator, scoped keys, hover opt-out, device prompts), `motion` (cascade, press, wipe, flyTo, sweepReveal), `hud` (date, clock, moon), `water` (WebGL caustics, bubbles, pause control), `color` (contrast).
- First consumer: Atelier6K demo on branch `design/atelier-ds`.
